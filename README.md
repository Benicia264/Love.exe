# Love.exe

### *Ah, l’amour ! — Découvre ton profil amoureux.*

---

**Love.exe** est une application web interactive qui explore les comportements amoureux à travers un quiz humoristique. Réponds aux questions, découvre ton profil et prépare-toi à quelques vérités qui piquent.

## Présentation

L'amour n'est pas toujours aussi simple qu'il en a l'air. **Love.exe** propose une expérience ludique pour découvrir son profil amoureux à travers des questions personnalisées et des résultats décalés.

L'objectif : se divertir, se reconnaître dans les résultats et partager l'expérience avec ses proches.

## Fonctionnalités

- **Quiz personnalisé :** des questions adaptées au parcours choisi.
- **Profils amoureux :** une analyse humoristique des réponses.
- **Résultats interactifs :** des commentaires décalés et des vérités qui piquent.
- **Partage :** la possibilité de faire découvrir l'expérience à ses proches.
- **Design responsive :** une interface adaptée aux mobiles et aux ordinateurs.

## Technologies utilisées

| Technologie | Utilisation |
|:--|:--|
| **React** | Interface utilisateur |

| **JavaScript** | Logique interactive du quiz |

| **Lucide React** | Icônes de l'interface |

## Installation

### Prérequis

- Node.js
- npm
- Git

### Cloner le projet

```bash
git clone URL_DU_DEPOT
cd NOM_DU_DEPOT
npm install
```

## Lancement en développement

```bash
npm run dev
```

## Build de production

```bash
npm run build
```

Pour prévisualiser la version compilée :

```bash
npm run preview
```

## Déploiement

L'application peut être hébergée sur GitHub Pages. La configuration de Vite doit tenir compte du chemin utilisé par le dépôt.
