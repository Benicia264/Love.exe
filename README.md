Love.exe — Ah, l’amour !

Love.exe est un quiz interactif et humoristique qui explore la personnalité amoureuse. Réponds aux questions, découvre ton profil et prépare-toi à quelques vérités qui piquent.

Fonctionnalités

* Questions adaptées au genre sélectionné.
* Profils amoureux et résultats humoristiques.
* Partage des résultats.
* Interface responsive, adaptée aux mobiles et aux ordinateurs.

Technologies

* React
* Vite
* JavaScript
* CSS
* Lucide React

Installation

Clone le dépôt :

git clone URL_DU_DEPOT
cd love.exe
npm install

Lance le serveur de développement :

npm run dev

Build de production

Pour générer la version de production :

npm run build

Pour prévisualiser cette version :

npm run preview
